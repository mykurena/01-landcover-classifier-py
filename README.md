# Landcover Classifier (PyTorch / Python)

Este proyecto contiene un clasificador de cobertura terrestre (Landcover Classification) desarrollado en Python.

## Estructura del proyecto
- `01-landcover-classifier-py.ipynb`: Notebook principal con el desarrollo, análisis de datos y entrenamiento del modelo.

## Requisitos
- Python 3.8+
- Jupyter Notebook / JupyterLab
- PyTorch / torchvision (u otras librerías necesarias especificadas en el notebook)
